# Security Policy

## Supported Versions

We release security updates and bug fixes for the latest major version.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The project team and maintainers take security seriously. If you discover a security vulnerability, please do **NOT** open a public issue.

Instead, please report security vulnerabilities responsibly by emailing our security team:

* **Email:** `security@asyntec.cl` (or via GitHub Private Vulnerability Reporting)

### Information to Include in Your Report

* Description of the vulnerability, including attack vector and potential impact.
* Step-by-step instructions or proof-of-concept (PoC) to reproduce the issue.
* Affected components (e.g. Orchestrator API, Wine Manager, Display Manager, Container Base).
* Any suggested fix or remediation if available.

### Response and Disclosure Timeline

* **Initial Response:** Within 24-48 hours acknowledging receipt of the report.
* **Triage & Status Update:** Within 5 business days with assessment and mitigation plan.
* **Patch Release:** Security patches will be released in an expedited patch version.
* **Public Disclosure:** Coordinated disclosure will occur only after a fix is available and verified.

Thank you for helping keep our software and users safe.
